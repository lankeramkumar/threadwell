enforces it, and says what is still verified by hand. A gate marked **manual** is not proven by the automated suite.

## What a reviewer should check by hand

1. Install the MSI on a machine without the development tools and create a workspace.
2. Turn on the sample project, search, edit a page, close the app, reopen, and confirm the edit is there.
3. Ask the assistant a question with the local model running, and confirm each citation opens its page.
4. Apply and undo one suggestion, and confirm the page content matches the undo.
5. Import a transcript and confirm each claim links to segments.
6. Create a recipe with a daily time, wait for it to run while the app is open, and review the draft.

## Known gaps against the brief

- Milestone 2 cloud providers are not built. The brief's second adapter is deferred by your decision.
- Audio transcription is not built. It needs an engine that is not configured.
- Scheduled runs happen only while the app is open. No background service is installed.
- Semantic evaluation needs a human rubric review. The automatic checks in the harness are heuristics.
