# Demo project: Harbor Bakery

A fictional bakery chain with three shops (Harbour, Riverside and Market Street). Use it to try every part of
Threadwell with realistic material. Everything here is made up.

Generated by `scripts/make_demo_project.py`. Run that script again to regenerate the folder.

## What is in the folder

| Folder | Type | Files | Use it to try |
| --- | --- | --- | --- |
| `notes-md/` | Markdown (.md) | 10 | Folder import: headings, checkboxes and bullets come through as formatted pages |
| `notes-txt/` | Plain text (.txt) | 10 | Folder import of plain notes |
| `documents-docx/` | Word (.docx) | 10 | Folder import: headings, lists and text are converted to Markdown |
| `documents-pdf/` | PDF (.pdf) | 10 | Folder import of text-based PDFs (layout is not kept) |
| `meetings-vtt/` | WebVTT transcript (.vtt) | 10 | Meetings → Import file, then extract notes and actions |
| `meetings-srt/` | SubRip transcript (.srt) | 10 | Meetings → Import file, then extract notes and actions |

The same ten topics appear in each note format, so every note type covers the same subjects:

1. Ordering app requirements
2. Supplier contracts: flour and butter
3. Seasonal menu pricing
4. Staffing and the weekly rota
5. Riverside shop opening checklist
6. Food safety audit results
7. Autumn marketing campaign
8. Loyalty programme design
9. Equipment maintenance schedule
10. Q4 financial summary

The meeting transcripts are ten calls, one per topic, each in both caption formats (ten `.vtt` and ten `.srt`).

## Things planted on purpose

- **Price conflict.** The seasonal menu note says the croissant is 3.20 pounds, but finance asked for 3.50 pounds.
  Ask the assistant "What price did we agree for the croissant?" and check that it reports both figures.
- **Open date.** The Riverside opening date depends on the inspection. A good answer says so.
- **Unstated deadlines.** Tasks in the notes have no due dates. Turning them into tasks should not invent any.

## A 20-minute walkthrough

1. **Create a workspace** in an empty folder. Untick the sample project, because this folder is your material.
2. **Import the notes.** Settings → *Import a folder of notes* → choose `samples/demo-project`. Tick
   the `.md`, `.txt`, `.docx` and `.pdf` files (the list shows 40 importable notes). Import them.
   Transcripts (`.vtt` and `.srt`) are not listed here; they are imported in step 4.
3. **Search.** Type `pumpkin` in the sidebar search. Results should include the menu, marketing and Q4 notes.
4. **Import one transcript.** Meetings → Import file → `meetings-vtt/meeting-food-safety-audit.vtt`.
   Choose *Extract notes and actions*. Check that each line has evidence timestamps, and that action items with no
   stated date have no due date. Apply the action items card.
5. **Ask the assistant.** Once a model is set up (see the README), ask:
   - "How much did revenue grow in September?" (answer should cite the Q4 financial summary: 118,000 against 111,000 pounds)
   - "What is the Riverside opening date?"
   - "What did we decide about the butter contract?"
   Click each numbered source to confirm it opens the right note.
6. **Try a suggestion.** Ask the assistant to create tasks from the equipment maintenance note. Review the card
   before you click Apply, then try Undo.
7. **Make a recipe.** Recipes → New recipe → instructions "Summarise the open tasks by shop." Choose Run now,
   then Review draft.
8. **Back up.** Settings → Create backup, then restore it into an empty folder to see the round trip.

The assistant's answers depend on the model you installed. Check every answer against its cited note.
